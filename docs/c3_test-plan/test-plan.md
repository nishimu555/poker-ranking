## 2. テストの方針

| サイズ | 定義 | 実行環境 | 実行者 | テストツール | 由来 |
|---|---|---|---|---|---|
| Small | 1 プロセス内で完結。実行環境固有の機能（`SpreadsheetApp`、`PropertiesService`、`HtmlService` 等）は代用品（Jest の `jest.fn()`）に置き換える。画面は DOM・canvas から分けた、表示内容を作る関数を対象とする | ローカル（Dev Container 内の Node.js v24.21.0） | AI | Jest（`npm test`） | implementation-plan.md 2.（テストの実行環境とツール）、c1/Question-006・010・023 |
| Medium | 1 つのデプロイ先（テスト用の入力用・閲覧用スプレッドシートと集計用プロジェクト）で完結する、実際のシートの読み書き、メニュー・メッセージの表示。Dev Container の作成の確認を含む | デプロイ先（テスト用の環境）。Test-097 のみローカル（Dev Container） | 開発者 | 手動（6. の手順に従う） | c3/Question-001・002、component-design.md 7.（テストのしやすさ） |
| Large | Web アプリ・スプレッドシートの共有・Google アカウントをまたぐ、利用者の操作を通した確認（画面の表示、アクセス制御、画像の保存・共有、データ量、デプロイ） | 実機・外部サービス（iPhone（Safari）、Google アカウント、テスト用の環境） | 開発者 | 手動（6. の手順に従う） | c3/Question-001〜005、component-design.md 7.（テストのしやすさ） |

- Medium・Large テストは、本番とは別に作るテスト用の入力用・閲覧用スプレッドシートと 2 つの GAS のプロジェクト（集計用・閲覧用）で行い、本番と同じ手順でデプロイする（c3/Question-002、Quality-007）。
- AI は Google アカウントの認証情報を扱わないため、デプロイ先・実機のテストは開発者が実行する（CLAUDE.md 4.、implementation-plan.md 2.、c3/Question-001）。

### デプロイ手順

コードでデプロイする（由来：CLAUDE.md 4.、implementation-plan.md 2.（デプロイの方法）、Quality-009。設定ファイルの名前・置き場所と閲覧用のデプロイの更新は、c2 の実装（`docs/c2_implement/implementation-design.md`「デプロイの処理」「5. 計画との違い」）に従う）。コマンドは Dev Container の中で実行する。

```
npm ci
npm test
npm run deploy:aggregate
npm run deploy:viewer
```

- `npm run deploy:aggregate`：ビルドして、`dist/aggregate/` の中のファイルのみをテスト用の集計用プロジェクトに送る（`clasp push`）。`.clasp-aggregate.json` がない、`rootDir` が `dist/aggregate` でない、`scriptId` が空の場合はエラーで止まる。
- `npm run deploy:viewer`：ビルドして `dist/viewer/` の中のファイルのみを送り、既存の Web アプリのデプロイを新しい版に更新する（URL は変わらない）。`.clasp-viewer.json` に `deploymentId` がない場合はエラーで止まる。
- **閲覧用の初回のみ**（`npm run deploy:viewer` は `deploymentId` がないと送る前に止まるため、初回は次の手順でデプロイを作る）：
  1. `npm run build` を実行する
  2. `npx clasp --project .clasp-viewer.json push --force` を実行し、`dist/viewer/` の中のファイルのみを送る
  3. GAS のエディタで閲覧用プロジェクトを開き、「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」で、次のユーザーとして実行「ウェブアプリにアクセスしているユーザー」、アクセスできるユーザー「Google アカウントを持つ全員」としてデプロイする（`src/viewer/appsscript.json` の設定と同じ：Decision-0001）
  4. 表示されたデプロイ ID を `.clasp-viewer.json` の `deploymentId` に記入する。以降は `npm run deploy:viewer` で同じデプロイを更新する
- **集計用の初回の実行**：テスト用の入力用スプレッドシートでメニュー「初期設定」を初めて実行するときに、権限の許可を求められる（スプレッドシートの読み書き、メニュー・ダイアログの表示）。
- 確認すべき出力：各コマンドがエラーなく終了すること。`npm run deploy:viewer` の後に表示される Web アプリの URL（2 回目以降も変わらないこと：Test-125）。

### 実施手順と結果の記載方法

1. 「5. Medium・Large テストケース」の実行者が開発者のテストケースを、Test-097 から番号の順に実施する（Test-100〜Test-109 はテストデータ A を使い、前のテストで変更したデータは各テストの手順に従って元に戻す）。
2. 結果を `docs/c4_test/test-report.md` の該当テストケースの結果欄に記載する（成功／失敗、実施日、失敗時の状況）。
3. `/c4-test` を実行すると、AI が結果を確認・集計する。
