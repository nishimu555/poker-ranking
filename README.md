# poker-ranking

テキサスホールデムポーカーのプレイ結果を Google スプレッドシートに記録し、ランキングとして可視化するアプリケーションです（Google スプレッドシート＋Google Apps Script）。

本リポジトリは AI 駆動開発で進めています。進め方は `CLAUDE.md`、各工程の進捗は `plans/README.md` を参照してください。

セットアップ手順は d1（セットアップ手順）の工程で追記します。
